# 출진/대화 화면 보충 조사 (v0.4 근거 문서)

> 조사일: 2026-08-07. campaign-ux.md의 [미확인] 항목 보충 — Bing 이미지 검색으로 원작 스크린샷을 직접 육안 확인해 대화/선택지/전장지도 UI를 확정. 출진 화면 스크린샷은 미확보.

## 1. 조조전 출진 화면 [부분확인]

- **[확인]** 출진 화면에 정렬 기능 존재 — "출진-부대속성순" 27병과 우선도 순서가 문서화됨(나무위키 병과). 장수 일람과는 다른 독립 화면. 출진 정원은 전투마다 상이(성도 침공전 13명 등).
- **[미확인]** 리스트/그리드형, 컬럼 구성, 순서 표시 방식, 맵 미리보기 유무.
- **[확인] 유닛 정보 패널 7필드** (전투 중 호버, 출진 리스트 컬럼의 최선 근거): 초상 / 이름 / 병과 / Lv / HP(현재·최대+바) / 사기(현재·최대+바) / Exp.

## 2. 조조전 대화 장면 [확정 — 스크린샷 실측]

- 원작은 **화자를 따라 이동하는 말풍선형 박스** (좌하/좌상/중앙상단 관측): 크림색 배경+베벨 테두리, 폭 70~80%, 3줄 고정, 초상은 박스 안 좌/우(박스 위치 따라 flip), 이름 라벨 파란 글자, 맵 위 화자 스프라이트 옆 하얀 말풍선 아이콘 이중 표시.
- **선택지 UI**: 초상 왼쪽 + 번호 옵션 세로 스택 + 선택 항목 전체폭 파란 하이라이트 바(커서 모델).
- **내레이션은 별개 레이아웃**: 초상·이름 없는 전체폭 하단 검정 박스 + 흰 글씨 3줄.
- 화면 크롬: 스토리 중 상태 스트립에 사실-가상 게이지(노랑/파랑 2색 + 깃발 아이콘).

## 3. 조조전 전장 지도 PiP [확정]

독립 플로팅 윈도우(타이틀바+닫기, 드래그 이동): 축소 맵 비트맵 + **파란 사각=아군/빨간 사각=적군** + 흰 테두리=현재 뷰포트. 화면 폭 25~35%.

## 4. 현대 SRPG 출격 준비 관례

- FE 3H/Engage: 로스터 선택과 맵 배치 2단계 분리, 강제 출전=사전 배치+녹색 하이라이트+해제 불가, 커뮤니티 불만 1위는 정렬/필터 부재.
- Triangle Strategy: 슬롯 중심 토글(select-then-place). Tactics Ogre Reborn: 프리셋 파티. Wargroove 2: 시작 세트 3택 카드.
- 웹 베스트 프랙티스: ①2-pane(로스터+맵)에 **동일 숫자로 연결** ②고정 슬롯 swap 모델 ③정원 카운터 상시+강제 자물쇠+사유 토스트 ④자동 편성/직전 복원 ⑤명시적 시작 게이트+미충족 사유.

## 5. VN 대화 화면 웹 관례 (Ren'Py 표준)

- 텍스트박스: 하단 고정, 높이 26%, 대사 폭 58%, 이름 라벨 박스 좌상단(위에 걸침), 이름 = 대사 1.35배.
- 키맵: Space/Enter/좌클릭 진행, Ctrl 홀드 스킵, A 오토(기본 OFF — WCAG 2.2.1), 휠업 백로그.
- 접근성: 타이핑 노드 aria-hidden + sr-only aria-live에 줄 완성 시 1회 커밋, 완성 후 80~120ms 입력 가드, rAF 기반 cps.
