### 소지·사용 규칙 (엔진 확정)

- **군 전체 공용 창고** (부대별 소지 아님). 종류별 재고 1바이트 = **상한 255**
- 대상: **자기 자신 + 주위 8칸(체비쇼프 ≤1, 대각 포함) 같은 진영** — 에러 문자열 「周围八格」
- **이동 후 사용 가능** (착지점 기준 사거리 판정), **사용하면 그 부대 행동 종료**
- 실패(조건 미달 강제 실행) 시 재고·행동비트·RNG 전부 무변화
- 메뉴: 수량 > 0인 소모품만 열거, 조건 미달 행은 **수량과 함께 남되 비활성** (인수 = 승급 조건, 경험열매 = 만렙 미만)
- 장비(인스턴스·레벨·슬롯 창고)와 소모품(종류별 카운트)은 저장 구조 자체가 분리 — ID 공간도 1–86 / 87–103

## 2. 범위(AoE) 책략 조준 규칙 (엔진 확정)

1. **빈 칸 중심 지정 불가** — 조준 후보 열거와 실행 모두 유닛 목록 기준. 영향 범위는 타일이 아니라 **유닛에 앵커** ("대상 유닛 선택 → 발밑 스플래시")
2. **유효 대상 0명 캐스팅 불가** (메뉴 비활성). 단 **효과 0 캐스팅은 플레이어에게 허용** — 만피 회복·중복 디버프 가능, 경험치도 획득 (「効果がない場合でもかけることはできるし経験値も獲得できる」 knack.htm). "무이득 금지"는 AI 전용 게이트 → **회복책략 노가다의 근거이므로 막지 말 것**
3. **아군 오사 없음** — 범위 내 타 진영 유닛은 0뎀이 아니라 **아예 건너뜀**. 진영 필터는 책략별 디스패치 비트. 유일 예외 = **현무(무차별 전체)**. 백호 = 전맵 아군 한정
4. 원작 하이라이트: 이동 = 파랑/대상 = 빨강 50% 체커보드 디더, 일반공격 = 속 빈 외곽선, 책략·도구 = 채운 면. **AoE 발자국 프리뷰는 원작에 없었을 가능성 높음**(프리뷰 함수가 렌더 계층에서 미호출) → ekd5의 AoE 프리뷰는 원작 초월 QoL로 분류
5. 공격계 책략은 **대상 지형 게이트** 있음(화계 = 실내 등 불가, 테이블 실값 미확보)

## 4. 인수(印綬) 전투 사용 상세 (promotion.md §4 보강)

- 대상: **자신 + 인접 8칸 아군** (자기 전용 특례 없음 — 진영·거리 검사가 타입 스위치보다 먼저)
- **승급하면 그 턴 행동 종료** / **이동 후 승급 가능** (원자적 액션이 착지점+대상을 함께 담음)
  → 「HP 깎였을 때 쓰라, 단 이동력이 오르면 1턴째에 쓰라」 정설의 전제
- 레벨 게이트 구조: 요구 = K×(차수+1), 승급 = 직업번호+1, 3차가 최종. 조조전 K=15 (Lv15/Lv30 — 15는 2K=30에 부합하는 유일값)
- 효과: 장기 HP/MP에 **구 병과 성장치×2**를 영구 가산(포화, 랩 없음) 후 **새 병과+현 장비**로 상한 재계산, HP/MP 완전회복. 장비 보정을 영구값에 역기록 금지 → ekd5의 "2차 hpBase = 1차 +2×성장치"와 수식 등가 ✓
- 조건 미달: 메뉴에 수량과 함께 남되 비활성, 강제 실행 시 무소모
- 확인창·연출: 코드·사료 모두 없음 (ekd5 오버레이는 QoL)
