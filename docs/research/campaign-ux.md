## 1. 전투 사이 화면 구성

### 조조전 — 막사(幕舎/本営/营地)
- **[확인] 기능 4가지** (百度百科): 장비 교체 / 아이템 매매 / 무장·아이템 상태 확인 / 출진(부대 선택 후 다음 스테이지).
- **[확인] 상호작용 = NPC 클릭이 곧 메뉴**: "XX, 창고를 열어라!" / "XX, 물자를 조달하라!" — 창고 담당·상점 담당 장수가 전투(막사)마다 다름. 정적 배경 1장 + 장수 도트 + 클릭 = 기능 진입.
- **[확인] 회의(작전회의)**: 회의장 참가 무장 6명(가끔 7명), 하후돈·순욱 등 고정 캐스팅 2~4명. 전투 후 "네 마디 나오고 바로 다음 전투"인 경우도.
- **[확인] 상시 HUD**: 우측 상단 사실-가상 게이지(합 100 고정, 데이터명 '야심', アライメントメーター).
- **[확인] 상점 재고 = 스토리 노드 단위 해금** (biglobe c05: "이 스토리부터 가죽 방패·천 장갑 구매 가능"). 나무위키: 장비 3단계(나무→구리→철) 해금이 에피소드 고정 — 밸런스 최대 단점으로 지적.
- **[미확인]** 막사 화면의 별도 커맨드 바 유무/버튼 라벨.

### 영걸전 도시 화면 — 조조전과의 차이
- **[확인]** 영걸전은 성내/외곽 포인트 클릭 이동 + 도시 방문 어드벤처 파트. **조조전에서 이동이 삭제되고 막사 내 대화만으로 간소화**.
- **[확인]** 영걸전 HUD: 유비 초상화 우상단(2시) 상시 고정(공명전/조조전은 제거), 좌상단 보석 오브젝트, "기능 메뉴" 존재.
- **[확인]** 영걸전 상점: 소모품+병과향상 아이템만, 아이템 소지 1인 8개 한도, 보물 판매 가능(조조전은 불가).

## 2. 출진(출격) 준비 화면

- **[확인] 출진 부대수 min~max가 스테이지 데이터**: 영천 1 / 사수관~동탁추격 4~7 / 청주·서주 6~10 / 복양Ⅲ부터 15 (최대 15). 절사평균 티어(4~7/8~11/12~15 구간별 상하 1~3명 제외 평균)가 **적 레벨 스케일링** 기준 (졸병=평균-2, 부장=+2, 주장=+4).
- **[확인] 강제출진**: 슬롯 앞 번호 고정(①조조②하후돈 — 번호=출진 순서). 조조는 전 전투 강제(퇴각=게임오버). **출진불가** 리스트도 존재(스토리 근거 첨부: "합비를 지키느라 위수에 올 수 없었다").
- **[확인] 선택 순서 = 맵 배치 위치** (핵심 발견): 스테이지마다 "슬롯 인덱스→좌표" 테이블 하드코딩. 예: 사수관 "第一列 위에서 ②④⑤③ 第二列 ⑥① 한 칸 띄고 ⑦". 복양Ⅱ/양산/마초 요격전은 슬롯 번호로 본대/별동대 분속 — 배치가 전략적 선택.
- **[확인]** 출진 리스트에 "부대속성순" 정렬 모드 존재(27개 병과 순서 명시). 표시 항목: 이름/레벨/병과/HP·MP/장비. **[미확인]** 정확한 레이아웃.

## 3. 전투 승리 후 처리

- **[확인] 경험치는 전투 중 인라인**: 매 액션 직후 데미지→경험치→레벨업/기술습득 즉시 표시. 종료 후 별도 exp 정산 화면은 미확인.
- **[확인] 전리품 3분류** (biglobe): 시설 점령 시 즉시 / 특정 적 격파 시 즉시 / **"勝利後(승리 후)" 지급** (예: "적 전멸시키면 승리 후 절영(絶影)") — 승리 직후 전리품 획득 표시 단계 존재. 인수(印綬, 클래스업 아이템)가 다수 전투의 승리 보상.
- **[확인] 사이클**: 스토리 노드(회의/선택지) → 막사(정비/상점/세이브) → 출진 버튼(→선택지 가능) → 출진 부대 선택 → 전투 전 대화 → 전투(중간 선택지/일기토/인접 대사) → 승리 → 전리품 → 다음 스토리 노드.
- **[확인] 스토리 노드 ≠ 전투 1:1**: 전투 없는 노드(15 사랑이여 안녕), 전투 뒤 후속 노드(10.2 전위의 죽음), 선택지로 전투 스킵(03 동탁 추격전), 클리어 방식으로 후속 전투 스킵(복양 전멸 클리어→Ⅱ·Ⅲ 스킵) → **캠페인 = 조건부 노드 DAG**.

## 4. 페이즈 전환 표시

- **[확인]** 아군(自軍)/적군(敵)/우군(友軍) 3세력 페이즈제. 우군은 조작 불가, 레벨 -1 역보정. 내부적으로 3진영 독립 컨트롤러(영걸전 디버그 모드로 확인).
- **[확인, 리메이크 기준]** 조조전 Online 색 규약: 적=파랑, 우군=보라, 아군 미행동=빨강, **행동 완료=흑백 전환**. 대장 표식 존재. **[부분확인]** 원작도 3세력 색분리+행동완료 그레이스케일.
- **[미확인] ⚠️ 페이즈 전환 배너의 문구/위치/지속시간** — 전 언어권 텍스트 소스로 확증 실패. 롱플레이 영상으로 확정 가능. (인접 확인: 턴 카운터/제한턴 상시 표시, 전투 중 우클릭 시스템 메뉴, 전투 연출 on/off 설정 존재)

## 5. 스토리 전달 방식

- **[확인]** 조조전 = 이동 없는 회의장 + 장수 클릭 대화. 무장별 얼굴 그래픽 보유(대사 시 표시).
- **[확인] 전투 중 인접 대사 이벤트가 조조전 강점**: biglobe가 전투별 "隣接時に台詞が出る武将の組み合わせ" 기록 → (유닛A, 유닛B) 인접 → 대사 트리거 테이블이 스테이지 데이터.
- **[확인] 사실-가상 게이지 UI**: 우측 상단 상시 노출, 합 100(빨강=사실/파랑=가상), 한쪽 85↑/15↓면 15 이하 게이지가 노란색으로 변해 진행 분기를 알림. 증감 폭 2/5/10/20 4단계. 분기 확정: 30번째 전투(마초 요격전) 후.
- **[확인] 전투 중 선택지**: 트리거(전투 시작/아군 1부대 퇴각/복병/10턴 경과/특정 유닛 HP/유닛 인접) → 효과(승리 조건 변경, 제한턴 변경, 원군 타이밍, 전리품, 후속 스테이지 분기).
- **[확인]** 영걸전 선택지는 즉사 선택지 존재 + 루트 분기(게이지 없음) — 성격이 다름.

## 7. 조조전 초반 스토리 구조 (서장~1장) [확인 — JP/KR 완전 일치]

- 프롤로그 00 영천 전투(난이도 E) → 제1장 「패왕 탄생」 01 사수관(C) → 02 호로관(B) → 03 동탁 추격전(A, 스킵 가능) → 04 청주 황건적(E) → 05 서주 보복전(B) → 06~08 복양 3연전(조건부 스킵) → 09 헌제 구출전 → 10 장수 토벌전+전위의 죽음 → 11 원술 → 12 장수Ⅱ → 13 서주 구원전 → 14 여포 포위전 → 15 (전투 없음, 장 종료). 번호 16~18 결번. 전체: 프롤로그→1장→2장(19~29)→3장 공통(30~35)→분기→종장. 루트별 총 40여 전투.
- **서장 상세 (온보딩 레퍼런스)**: 영천 = 출진 1부대(조조 Lv3, 의천검 소지) 튜토리얼, 나머지 전부 우군(유비 3형제 포함), 2턴에 허자장 튜토리얼+회차 보너스, 승리조건 장보·장량 격파/제한 20턴. 클리어 → 스토리(왕윤 칠성검) → **하후돈·하후연·악진·이전·조인·조홍 6명 일괄 합류** → 사수관(출진 4~7). = "1부대 튜토리얼 → 6명 로스터 → 4~7부대 정식 출진" 커브.

## 8. 적용 시사점

1. 막사 = 정적 배경 + NPC 클릭으로 충분 (메뉴 시스템 불필요)
2. 스테이지 스키마 필드: `deployMin/Max, forcedUnits[], bannedUnits[], slotIndex→coord[], turnLimit, winConditions[], allyUnits[], reinforcements[], loot[{trigger: occupy|kill|victory}], dialogueTriggers[], choices[]`
3. "선택 순서=배치 위치"는 저비용 고임팩트 기믹
4. 캠페인 그래프는 노드 DAG (`story | battle`)
5. 적 레벨 스케일링(절사평균)은 심장이자 최대 비판점 — 채택 시 장비 해금도 평균 연동으로
6. 세이브는 조조전 방식(언제든+번호 슬롯)이 현대적
7. 메타 진행(도감/회차)은 세이브와 분리

# 2부. 현대 택틱스 메타게임 UX (Athena Crisis 소스 실측 중심)

## 1. 페이즈 배너 (Athena Crisis `hera/ui/Banner.tsx` 실측)

| 항목 | 값 |
|---|---|
| 시간 단위 | `AnimationSpeed=180ms`, `AnimationDuration=360ms` |
| 레이아웃 | `position:fixed; inset:0` + Portal, 세로 중앙 전폭 가로 밴드, `pointer-events:none` |
| 테두리/배경 | 상하 흰 보더만, 진영색 그라디언트 α0.9 + 노이즈 마스크(3~5s 저주파 루프) |
| 진입 방향 | **진영별 반대 방향**(방향 자체가 소속 신호) |
| 애니메이션 | spring + 글자 단위 stagger 24ms |
| 턴 배너 총 길이 | 약 0.7~0.9초 |
| 텍스트 | "Round {n}, {진영명}" — **턴 수 병기** |
| 스킵 | Instant 설정 시 배너 자체 생략. 속도 3단계: Normal / **FastAI(적만 ÷4)** / FastAll |
| 재사용 | 게임 시작/목표 달성/패배/공지 전부 같은 Banner — **범용 전면 알림 슬롯** |

- FE 관례: PLAYER/ENEMY/OTHER PHASE + 파랑/빨강/초록. Into the Breach 교훈: 배너는 2차 신호, 1차 신호는 보드(유닛 테두리색, 행동완료 그레이아웃).
- 접근성: `prefers-reduced-motion` 시 즉시 표시+짧은 유지, 색+텍스트+방향 3중 인코딩, `role="status" aria-live="polite"`.

**ekd5 채택 스펙**: 전폭 밴드, "제 N 턴 · 아군/적군/우군 페이즈", 아군 좌→우/적 우→좌, BASE=180ms (진입 220→유지 500→퇴장 180 ≈ 0.9s), 클릭 즉시 완료, 속도 설정 연동.

- **FE Engage Somniel = 반면교사**: 걸어다니는 3D 허브는 "지루하고 번거롭다"는 강한 합의 → 메뉴형 허브가 정답.
- Wargroove: 월드맵 마커+점선 경로(스테이지 8개+ 분기 생기면 도입). Athena Crisis 캠페인 노드: 맵명/목표/보상/등장 캐릭터 초상.
- **ekd5 채택**: 3열 그리드 1화면(좌=다음 전투 카드: 승리·패배 조건 자동 렌더+적 규모 / 중앙=로스터: 이름·병종·Lv·EXP바 / 우=선택 유닛 상세), 헤더에 진행도+자동저장 인디케이터, 출전 버튼 최강 시각 요소. 라우터 없이 `Screen` 유니온.

## 4. 세이브 UX (웹)

- 브라우저 스토리지는 기본 best-effort(LRU 삭제 가능) → `navigator.storage.persist()` 승격 필요(Chromium 자동 판정/Firefox 팝업).
- localStorage <1MB, 그 이상 IndexedDB. **version 필수**. 모바일은 `visibilitychange`가 신뢰성 높음(beforeunload는 동기 localStorage만 가능).
- **파일 export/import 제공** = 소실 대비 유일한 보험. New Game 덮어쓰기 사고 흔함 → 확인 다이얼로그 필수([취소] 기본 포커스).
- **ekd5 채택**: IndexedDB 본체 + localStorage 메타 미러(타이틀 즉시 Continue 판단), 자동 저장(승리 확정/캠프 진입), 첫 저장 성공 시 persist() 1회, 인디케이터는 헤더에 작게("자동 저장됨 · 방금"), 실패 시에만 강조.
