## 3. 계열별 고유 특성 (ja.wikipedia 원문)

- **무도가(武道家)**: 곤봉, 순발↑(연속공격·회피↑), **수상 지형 적성↑**, 독연/기합 책략. 전위 전용.
- **무희(踊り子)**: 곤봉, 상태이상 아군 인접 시 **춤으로 회복(패시브)**, HP 낮음, 향상계/유혹(誘惑·HP흡수)/환혹(幻惑·퇴각) 책략. 초선/축융.
- **포차(砲車)**: 포, **전 병과 최장 사거리 간접공격**, 명중 낮음·이동 좁음, 클래스업 시 **대상 인접 적에도 피해(광역)**. 유엽 전용. 바람바퀴(風の車輪) 전용 병과 — 장비 특수효과(v1.3)와 연결.
- **적병(山賊)**: 검, 숲/산악 지형 적성↑, **지계 공격책략**, 사기↑(회심↑), 정신↓. 허저 전용.
- **기마책사(騎馬策士)**: 부채, 기동 문관.
- **황제(皇帝)**: 비무장 호송 유닛(공격 자체 불가). 스테이지12(헌제 구출전) 호위 대상.

## 4. 엔진 적용 사항

1. **체비쇼프(8방/ロ) 공격범위**: 무도가·무희·적병·보병·기병3차·군주2차가 8방. 현재 코어는 맨해튼 기반 — `attackableCells`/battle/UI/AI에 **8방(체비쇼프≤1) 사거리 모드** 추가 필요.
2. **포차 광역·장사거리**: 전 병과 최장 사거리 간접 공격 + 2차부터 대상 인접 광역. 개별 공격 타입에 광역 물리 필요.
3. **무희 상태회복 패시브**: 인접 상태이상 아군을 페이즈 시작 시 자동 회복.
4. **황제**: 공격 불가(범위 -) host 유닛. 승급 없음.
