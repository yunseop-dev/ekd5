## 2. 턴 종료 방식

- **영걸전(SFC판) — 확정**: 시스템 메뉴에 **"End turn(턴 종료)" 커맨드 존재**. [EN GameFAQs]
- **영걸전(GBA판) — 확정**: 취소 버튼으로 턴 종료 확인 호출, **모든 유닛이 행동을 마치면 확인창이 자동으로 표시** (= 확인 프롬프트형). [EN GameFAQs]
- **조조전(PC)**: "전원 행동 완료 시 자동 이행" 통설이나 문헌 미확보 — **확인 불가**. 위임/자동전투 기능은 존재 흔적 없음(간접 확정). [CN 간접] 优化补丁 기능 목록: https://tieba.baidu.com/p/3358316868

## 3. 적군 턴 연출

- 카메라 추적/생략 옵션 직접 서술 **확인 불가**.
- 간접 증거: 중국 팬패치(优化补丁/변속기어)가 **Ctrl 배속, 속도 조절, 행동 순서 표시, HP바 표시, 예측 대미지**를 별도 구현 → **원작에는 배속/스킵·HP바 상시 표시·대미지 예측이 없었음을 강하게 시사**. [CN] https://tieba.baidu.com/p/3358316868
- 조조전 온라인(2016)이 "배속/스킵"을 셀링포인트로 추가. [KR] 게임메카: https://www.gamemeca.com/view.php?gid=936387

## 4. 지형 정보 표시

- **영걸전(콘솔) — 확정**: 커서 위치의 **"Panel Data" 창 상시 표시** — 지형명/지형효과(방어 %)/회복(점유 유닛 HP·SP 재생) + **커서 위 유닛 정보 동시 표시**. 전장 상단에 승리조건/날씨/턴수. [EN GameFAQs]
- 영걸전 지형효과 예: 평지 0%, 초원 5%, 다리 0%, 요새 30%, 마을 5%(회복), 병영 10%, 숲 20%, 산 30%. [EN GameFAQs]
- **조조전 — 확정**: **지형 정보 일람 창** 존재. 병과별 **이동코스트 = 숫자 색상(1=파랑, 2=초록, 3=주황)**, **지형효과 = 심볼+배율(80%=X 보라, 90%=△ 파랑, 100%=○ 초록, 110%=◎ 주황, 120%=★ 황금)**. 성·관문·요새=120%, 마을·병영=110% + **매턴 최대 HP 20% 회복**. [KR] 나무위키 조조전/병과
- 지형효과는 **물리 공격에만** 적용(책략·명중 무관). [KR] 디시 수치분석: https://m.dcinside.com/board/game_classic/456763

## 5. 반격 규칙

### 조조전
- **반격 데미지 = 공격 데미지의 80%** ("反击伤害是攻击伤害的80%"). **[CN 확인]** 百度经验: https://jingyan.baidu.com/article/aa6a2c140d52570d4c19c499.html
- **반격 조건 = 공격자가 방어자의 공격범위 안에 있을 것**:
  - 궁병계는 인접 적 공격 불가 → **인접 melee에게 맞으면 반격 불가**. [JP] ja.wikipedia 三國志曹操伝
  - **원거리(사거리 밖) 공격에는 반격 불가** — 같은 규칙의 귀결. 신조조전 MOD의 "무조건반격(범위 무관)/무반격공격" 특성 존재가 방증. [KR] 나무위키 신조조전/특성
  - melee ↔ melee 인접 공격 → 반격 발생. [KR 시리즈] 더위키 영걸전
- 조조전 반격은 확률제 아님(생존+범위 조건 시 항상 발동) — 통설, **직접 확증 실패**.
- 미스 시 반격 여부 / 2회 공격과 반격의 순서: **확인 불가**.

### 영걸전 (PC ↔ 콘솔)
- 콘솔판 — 확정: 전 부대 반격 가능하되 **공격 범위 안에 적이 있을 때만**, 확률 = 병종+사기(보병 사기100 = 20% 최고, 주술사/수송대 5%, 사기 0 = 0%). [KR] 더위키/나무위키
- 간접(원거리·대각) 공격에는 반격 불가: 궁병은 대각 인접이어도 적병대/무도가 반격을 안 받음. [KR] 더위키 영걸전/병과

## 6. 전투 진행 연출

- **별도 전투 화면 없음 — 확정**: 맵 위 유닛 스프라이트가 직접 공격 모션. **빗나가면 막기(격당) 모션**. HP 0 = "퇴각" 표시 후 소멸, 특정 상황 사망 전용 효과음. [CN] 百度百科 三国志曹操传: https://baike.baidu.com/item/三国志曹操传/5353432
- 행동 완료 유닛의 회색 표시 / 이동 경로 표시 / 데미지 숫자 팝업: **확인 불가** (优化补丁이 HP바·예측 대미지를 별도 추가한 점에서 원작 부재 간접 확정).

## 부록: 확보 수치

- 물리 대미지 = ((공격×지형효과) − (방어×지형효과))/2 + 레벨 + 25 (+소량 난수, 최소 1) [KR 디시]. CN 회귀분석은 상수 28로 상이 — 병기, 실측 검증 권장: https://www.sanguogame.com.cn/special/ccz/ccz-xd2.html
- **상성(조조전, CN)**: 弓克骑/맹수, 骑克步, 步克弓 — **단방향 +50%** [CN 百度经验]. KR 나무위키(궁→기 +50%만 명시, 나머지 스탯 창발)와 충돌 → 리메이크는 CN 삼각 상성 채택, 충돌 주석 명시.
- 지형: 총 30종 중 진입 불가 12종, 이동 코스트 1~3, 성·관문 전 병과 코스트 1. [KR 나무위키]
