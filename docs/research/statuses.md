## 1. 상태이상 — 정확히 4종 (매혹은 원작에 없음)

비트필드 완전 중첩: `0x02 부동(麻痹) | 0x04 금책(禁咒) | 0x08 혼란(混乱) | 0x10 독(中毒)`.
**매혹/매료는 원작에 존재하지 않는다** — 해제 수단 목록(해제약 5종·각성·백호·태평청령서)이 4종으로 닫혀 있고
계략 73건 전수에도 없음. caocao.md §3의 "+매혹"은 조조전 Online 오염 (교정함).

| 상태 | 효과 (전부 엔진/역어셈블 확정) |
|---|---|
| **독** | 매턴 자기 진영 페이즈 시작 시 `max(1, floor(maxHP/10))` 데미지. **사망 불가 — HP는 1에서 정지** (`HP = max(1, HP-dmg)`, 0x44DFC7/0x44E020) |
| **혼란** | **행동 완전 불가**(랜덤 오조작 아님) + **물리·책략 확정 피격**(명중 100 강제, 즉사기 해일·현혹만 예외) + 반격 불가. 귀결: 각성약 자가 사용 불가 |
| **부동** | **이동만 불가.** 공격·책략·도구·반격 전부 정상 (확정 피격 없음 — 6.5 MOD가 麻痹로 옮긴 것) |
| **금책** | **책략만 불가** (사신 포함). 물리·반격·도구 정상 |

- **지속턴 없음** — 부여 직후 첫 턴부터 순수 확률 판정 ("传统看脸". 1~3턴 고정은 6.5 MOD 신기능)
- **자연해제 확률 = 부대 사기(%) = floor(운÷2) + 레벨×성장치** — 인물 장기 레코드 기준.
  **사기 버프(고양·환성)는 회복률에 영향 없음** (전장 임시치가 아니라 장기 레코드를 읽음). 4종 동일 확률, 각각 독립 난수
- 미해결: 엔진에만 있는 혼란 −15 페널티(중·한 사료 미언급) — 미채택

## 2. 책략 명중 공식 — "한계명중"의 정체는 계수 α

```
x = (시전 정신+사기) / (대상 정신+사기)
y = x≥2:100 / x≥1:10x+80 / x≥0.5:60x+30 / x≥⅓:90x / 그 외:30   [30,100]
r = clamp( α × min(y + β', 100) + β, 30, 100 )
```
- **α(한계명중)는 별도 상한이 아니라 곱해지는 계수** — 명중 보조(칠성검 +15)는 괄호 안이라 천장이 α로 묶인다
- 특례: 대상 혼란 → r=100 (해일·현혹 제외) / 즉사기의 대상이 아군 주장(조조)·적 주장 → r=0
- 상태이상계는 지형·날씨 무관
- 3계통(중국 역어셈블·한국 역산·C# 엔진) 대수적 동일 확인. 해일 α는 33.33% (biglobe 50%는 오기)

## 4. 제2부(원작 c04~c15) 확정 사실

- **관해(管亥)·조표(曹豹)는 원작 미등장** (Data.e5 512인 전수) — c04 청주는 적장 없이 황건 익명 부대만. 관해는 영걸전 북해전 인물. 조성(曹性, 궁기병 72/74/50/64/76)이 c13에서 하후돈 눈을 쏘는 실존 적장
- **서주 학살 선택지 없음** — 조조가 학살을 명시 부정(`我没有打算屠杀徐州的百姓`). c05의 실제 선택지 = 여포의 복양 침공 급보 시 **「도겸과 화친/토벌 속행」** (게이지 무변동, 양쪽 다 백은갑옷)
- **c05 유비군 = 8턴 적 원군** (유비·관우·장비·조운). 우군은 c13(구원 선택 시)·c14(남쪽 숲)
- 복양 3연전: 전멸 클리어 시 후속 스킵(최소 1전), 보물 3종 분기(이광궁/연환갑/여포궁). 여포는 처음부터 내곽 배치 + 트리거까지 부동
- **하비(c14) = 설원 + 강 + 다리 2개, 악천후로 화계 불가·성내전으로 지·풍계 불가.** 수공/침수 연출은 원작에 없음. 승리 = 전멸 단일, 20턴 초과 패배. 여포→방천화극
- 합류: 우금(c06)·허저(**c08**, 스킵 시 c09)·서황/만총(c10)·**장료/초선/가후(c15**, 여포 격파 후. 장료 기병, 레벨은 아군 평균 연동)
- 적장 스탯(부대치×2=장수치, 전부 짝수): 여포 100/100/**12**/94/84 HP110 · 진궁 68/76/90/62/52 · 고순(서량기병) 88/90/48/62/38 · 도겸 74/64/72/58/56 · 허저 98/90/36/68/98 · 장료 92/84/86/78/94 · 유비 78/72/76/74/**100** · 관우 96/98/90/68/62 · 장비 100/74/46/72/76
- 게이지: c04 ±2, c10 10/5 비대칭, c12 ±2, c13 ±5(연의와 반대 방향). 내부명 「야심」, 판정은 3장 마초 요격 직후
