# 승급(인수) 시스템 정밀 조사 — 三國志曹操伝

> v0.8 보충 리서치(R 에이전트, 2026-08). 1차 사료 biglobe 공략법 원문 데이터와 한국 위키를
> 교차검증. `caocao.md` §2.1~2.2의 승급 서술을 이 문서가 대체·보강한다.

## 0. 핵심 결론 3줄

1. **승급은 능력치·성장률을 전혀 바꾸지 않는다.** 나무위키 원문: *"영걸전, 공명전과 다르게
   부대를 승급시켜도 능력치나 성장률에는 변화가 없다."* → "2차 성장 +1등급"은 조조전이 아니라
   **영걸전/공명전 문법**이다.
2. **인수는 전투 중에 쓰는 소모품**이다(장수 화면·창고가 아님). 사용 즉시 클래스업 + HP/MP가
   최대치로 회복 → **회복 아이템 겸용**.
3. **인수는 2장부터 상점에서 무제한 구매 가능**하다. 희소 자원 긴장은 **1장~2장 초반에만** 존재한다.

### 1-2. 상점 판매 — 가능

> biglobe c19 스토리 주석: 「このストーリーから印綬が購入できる。レベル１５または３０以上に
> なっていてまだクラスアップしていない部隊があれば事前に購入しておきたい。」

→ **2장 첫 전투부터 상점 상시 구매 가능.** 가격(금액)은 한·일·중 어느 사료에도 없음(확인 실패).

### 1-3. 희소성의 실체

- 아군 26명 × 승급 2회 = 인수 52개 필요. 드랍 최대 16개 → 31% 커버. 상점 무제한이므로
  최종적으로는 전원 승급 가능.
- 실제 긴장 구간은 **1장 중반~2장 초(약 8전투)**: "누구부터 승급시킬까"가 선택으로 작동.
  이후는 골드 기회비용으로 전환.

## 2. 클래스업 보너스의 정확한 규칙 ★

### 2-1. 확정 공식 (나무위키 「삼국지 조조전/병과」)

> *"클래스 업을 하면 그 순간 HP와 MP가 레벨 상승치의 2배만큼 증가한다. 이는 인수를 써서
> 플레이어가 직접 클래스를 올릴 경우에만 해당되므로 처음부터 클래스 업이 되어 아군에 들어오는
> 장수는 이 증가량이 반영되지 않는다. (…) 단, 영걸전, 공명전과 다르게 부대를 승급시켜도
> 능력치나 성장률에는 변화가 없다."*

**레벨당 HP 성장치 (병과 고정, 장수 능력 무관):**

| 성장치 | 병과 | 승급 1회 보너스(=×2) |
|---|---|---|
| +6 | 보병계 | +12 |
| +5 | 기마 전 부대(기병·궁기병·기마책사·군주) + 적병 | +10 |
| +4 | 궁병·무도가·포차·책사 | +8 |
| +3 | 도사·풍수사·무희 | +6 |

MP 성장치: 문관 +2 / 그 외 +1 (군주는 무관 취급, 제갈량 전용 +3).

### 2-2. 검산 — 조창

```
HP 107 (Lv1) + (50-1)×5 = 352      ← biglobe 味方武将一覧의 曹彰 Lv50 HP와 일치
352 + (2×5)×2회 = 372              ← thewiki "Lv50 및 인수 2회" 실측값과 일치 ✓
```

두 독립 사료가 공식을 양쪽에서 확정. 처음부터 상위 클래스로 참전하는 관우·방덕·조창(친위대)이
동레벨 대비 HP가 낮은 이유도 이 보너스 미적립 때문.

### 2-3. 능력치 성장 공식엔 클래스 항이 없다 (biglobe rule.htm)

> 「レベルＰの時の自軍部隊の能力＝［関連する基本能力÷２］＋［Ｐ×上昇数値］」

상승수치는 부대특성(S/A/B/C)과 장수 기본능력으로만 결정. 특성 등급 임계점은 기본능력 70/90
(→ "열매로 70·90 넘기기 전엔 레벨업을 참아라" 정설의 근거). **클래스 보정항이 구조적으로 없음.**

## 3. 병과별 승급 트리 실데이터 (biglobe 部隊一覧)

형식 = `이동력-공격범위(イロハ… 순서, 뒤로 갈수록 넓음)-영향범위`. 범례 페이지 유실로
절대 칸 수는 미확인, 상대 순서만 유효.

| 계열 | 1차 | 2차 | 3차 | 성장(공/정/방/순/사) |
|---|---|---|---|---|
| 군주 | 군웅 6-イ | 영웅 6-**ロ** | 패왕 **7**-ロ | A A A A A |
| 기병 | 경기병 6-イ | 중기병 6-イ | 친위대 **7**-**ロ** | S B A B B |
| 궁기병 | 궁기병 6-ハ | 노기병 6-**ニ** | 연노기병 **7**-**ト** | S B B B A |
| 보병 | 경보병 4-ロ | 중보병 4-ロ | 근위병 **5**-ロ | B A S B B |
| 궁병 | 궁병 4-ニ | 노병 4-**ト** | 연노병 **5**-**ヌ** | A B B B S |
| 책사 | 책사 4-イ | 참모 4-イ | 군사 **5**-イ | B S B B B |
| 도사 | 도사 4-イ | 환술사 4-イ | 요술사 **5**-イ | C S B A B |
| 풍수사 | 풍수사 4-イ | 방술사 **5**-イ | 선술사 **6**-イ | C S C A A |

읽히는 설계 규칙:
- **성장등급은 계열 단위로 1개** → 표 자체가 "승급해도 성장률 불변"을 증명
- **3차 승급은 예외 없이 이동력 +1** (2차에서 이동이 오르는 건 **풍수사→방술사(4→5)뿐**)
- **원거리 계열만 승급마다 사거리 확장** (궁병 ニ→ト→ヌ 등)
- **1→2차 수치 무변화 계열**: 기병·보병·적병·책사·기마책사·도사
- 문관 2차는 상위 책략 해금("한층 더 강력해진 공격계 책략"), 사신(四神) 책략은 3차 전용
  (주작=군사, 청룡=기마군사, 현무=요술사, 백호=선술사)

커뮤니티 정설(인수 우선순위): 첫 인수는 **곽가(도사→환술사)** — 허보(혼란)로 적 반격 봉인.
기병·보병 1→2차는 "외형만 변화"라 인수 낭비로 통한다(thewiki).

## 4. 승급 UI / 연출 / 타이밍 메타

| 항목 | 내용 | 확실도 |
|---|---|---|
| 사용 위치 | **전투 중 아이템 사용** (소모품) | 확정 (biglobe 2곳) |
| 효과 | 클래스업 + **HP/MP 최대치 회복** | 확정 |
| 획득→사용 | 전리품이므로 다음 전투부터 | 확정 (thewiki) |
| 확인창/연출/되돌리기 | — | 확인 실패 |

> biglobe knack.htm: 「印綬を使用してクラスアップするとＨＰとＭＰが最大値となるので、ＨＰが
> 減少したところでクラスアップすると効果的である。ただ、クラスアップすると移動力が上昇する
> ような場合は、最初のターンでクラスアップする方がよいかもしれない。」

타이밍 정설: ① HP가 깎인 뒤에 쓴다(회복 겸용) ② 이동력이 오르는 케이스만 1턴째에 쓴다
③ "늦승급이 성장에 유리" 정설은 **존재하지 않는다**(성장률 불변이므로 성립 불가).
적 레벨은 아군 출진 평균에 연동(러버밴딩, biglobe victory.htm) — 승급은 레벨을 올리지 않으므로
러버밴딩과 무관.
