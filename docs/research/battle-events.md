# 원작 전투 내 이벤트·대사 조사 (v1.1 R)

> 조사일 2026-08-11. 결론: **대사 원문은 c01 전투 중 선택지·c14 주변 스토리 씬 등 일부만 보존** —
> 개전 훈시·청주 3책 제안·하비 일기토 대사는 어느 공개 소스에도 없어 전부 [창작 필요].
> 대신 **발동 조건·결과·인접 대화 쌍은 전 전투 1차 소스(biglobe) 확정**. 창작은 §F 톤 가이드 준수.

## 0. 소스 교정 2건
- biglobe(~hampton)는 **UTF-16LE** (Shift-JIS 아님 — 오판 주의). `台詞` 항목의 정의 = "인접 시 대사가 나오는 무장 조합"(쌍 목록이지 텍스트가 아님)
- **ccz-compat-engine은 조조전 스크립트(S_*.eex)를 포함하지 않는다** (김용 무협 모드용 호환 엔진 — E5/EEX 포맷만 공유). 엔진 규칙(행동효과·아이템 게이트) 인용은 유효하나, **statuses.md의 S_05/S_13/S_14 "대사 인용"은 신뢰 불가로 정정** (전투 규칙·선택지 구조는 biglobe로 재확인된 것만 유지)
- 일기토 기호: ○승리 ●사망 ▲퇴각 △무승부

## 1. 청주(c04 = stage07) 3책 — 효과 확정
시점: 배치 후 개전 직전, 회피 불가. 선택지(한국어판): 「순욱에게 맡긴다 / 전위에게 맡긴다 / 순유에게 맡긴다」. 제안 대사는 [창작 필요].
| 선택 | 효과 |
|---|---|
| 순욱(권항) | 북서 산 **9부대가 설득으로 퇴각** → 잔존 18 |
| 전위(위압) | 각 산 2부대씩 **6부대 도주** + **잔존 15부대 전원 Lv+1** (병과 변경 아님 — 장비도 레벨 비례라 실질 강화) |
| 순유(유인) | 남동 부대가 시작지점으로 유인 — **적 9부대가 아군에게 포위된 형태로 재배치 + 그중 4부대 혼란**, 아군은 3덩이 분산 배치. 잔존 27(최다 경험치) |
c04는 인접 대화·일기토 모두 0 — 원작 서사 장치는 3책 하나뿐.

## 2. 하비(c14 = stage11) 일기토 4건 — 결과 확정
| 쌍 | 결과 |
|---|---|
| 초선 vs 조조 | **△ 무승부** (양쪽 무피해 추정 — 승자만 경험치 규칙) |
| 후성 vs 조조 / 위속 vs 하후돈 / 송헌 vs 하후연 | **● 적장 사망 / ○ 아군 승리** |
★ **"배반 일기토"는 원작에 없다** — 3인은 그냥 죽는다 (사서의 투항 전개 미채택). 배반 설계는 [의도적 이탈] 표기 필수.
★ **일기토 발동 = 지정 쌍의 인접/접촉 자동. 확인 프롬프트 없음** — 회피 = 붙이지 않는 플레이 (하후돈·하후연을 동쪽에 출진시키라는 공략이 "짝 만들기"의 근거). 연출은 별도 화면. 승자만 일반 격파 경험치, 무승부 무보상.
c14 여포 기동: 「友軍を含めて自軍部隊が４部隊以上城内にいるとAは動き出す」 — "4부대 이상"은 조조전 관용 트리거 수치 (c03 복병도 동일).

## 3. c13(= stage10) 확정
- **개전 즉시 스크립트 일기토: 조성 vs 하후돈 무승부** — 하후돈이 화살에 눈을 잃는다 (무승부+서사 결과 케이스)
- 개전 선택지: 「유비의 구원을 우선한다 / 하후돈의 원수를 갚는다」 — 후자는 유비군 미배치+여포 전군이 하후돈에 돌격
- **인수 조건 원문**: 「조조와 유비를 인접시키거나, 유비가 생존한 채 승리 — 중복 지급 없음」 (OR 2조건)
- 유비 퇴각 시 **미축이 여포를 배신해 유비를 대피시켜 게임오버가 안 되는 페이크 패배 조건**
- 인접 대화 조조×8인(여포/진궁/장료/고순/조성/후성/장패/유비) — 1부 최다

## 4. 1부 재편성 소재 (c00~c03)
- **c00(stage01/03)**: 턴2 **허자장이 부대 레벨업 제안**(수락=레벨+3~6/거절=소지금) — "대화 후 혜택"의 원작 정격 사례(giveExp choice). 원군 등장 시 적 전 부대 혼란. 장보·장량이 독연 사용. 인접: 조조×장보/장량
- **c01(stage04)**: 관내 8부대는 관에서 안 나옴(농성 부동). 일기토 화웅●vs관우○(우군). **전투 중 선택지 대사 원문 보존** — "아군 1부대 퇴각+적 8부대 잔존" 시 조조 상황 요약 → 퇴각/속행 → 후속 대사 (전투 내 대사의 문체 표본)
- **c02(stage05)**: 여포 포함 14부대 = 아군 접근 시 기동. **여포 격파 → 관내 부대 퇴각 + 관외 부대 혼란** (격파 연쇄 이벤트). 일기토 여포△×유비/관우/장비(우군, 전부 무승부)
- **c03(stage06)**: 복병 3그룹, 등장 조건 3중 OR(잠복지 접근/4부대 이상 성 동쪽/강 부근). 전투 중 선택지 "퇴각한다" → **승리 조건이 '조조 서단 도달'로 변경 + 적 전체 추격**. 전멸 시 절영(絶影) — c10 전위 구출 필수템이라 전멸 인센티브 근거
- 게이지: c00 ±10 / c01 ±5×2(초선 호감은 c04·c14 스크립트 분기 플래그) / c03 ±5 / c04 ±2. **전투 내 선택지는 게이지 무변동**

## 5. 인접 대화 쌍 전량 (텍스트는 전부 [창작 필요] — 설전 형식, 아군이 지기도 함)
