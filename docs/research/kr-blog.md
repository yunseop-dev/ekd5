## 1. 시스템 발견 (v1.2 반영 근거)

1. **턴 제한 = 패배 조건이며 UI가 `턴 수 n/20`으로 상시 노출.** 표준 20턴, 복양3만 25턴, 원술 정벌은 선택지로 12/20 가변 → `DefeatCondition.turnLimit` 도입 근거
2. **호위 대상 사망 패배** — 헌제 구출전 "헌제의 사망" → `unitDies` 근거
3. **한 선택지가 승리조건·턴상한·전리품을 동시에 변경** — 원술 정벌(군량 지원 = 20턴·전멸·인수X / 책임관 사형 = 12턴·원술 퇴각만·인수O) → `setVictory`/`setDefeat` 근거
4. **전투 결과가 승리조건을 바꾼다** — 동탁 추격전 "퇴각한다" → 승리조건이 "조조를 서단까지"로 전환 + **적 전체가 조조를 추격** → `setBehavior` officerIds 생략(전원) 근거
5. **화염이 지형을 바꾼다** — 화공 후 불꽃 타일이 여러 턴 잔존해 통로를 봉쇄. 장수 토벌전은 이를 "불을 이용한 방어진영"으로 씀 → `hazards` 근거
6. **지형 배율이 명시적** — 기병: 풀숲 90% / 여울 80% / 가옥 90% (기존 문서는 "악지 80%"만) → terrain 교정 + `ford` 신설 근거
7. **출진 슬롯 순번 = 맵 배치 위치** — "2~3번째 자리는 선봉이라 방어 높은 장수", "빨갛게 칠한 슬롯이 성안에 갇히는 병력" → 출진 화면 인과 시각화 근거
8. **아이템은 맵에 놓여 밟아 회수**, 획득 시 `{이름}을(를) 손에 넣었습니다!` 1줄 메시지 → `groundItems`/`dropItem`/획득 모달 근거
9. **아이템 귀속**: "모든 아이템은 아군이 입수하면 조조진영으로" → 공용 창고 확증
10. **적 AI가 트리거 기반** — "3턴에 자동 공격", "4턴 1진 / 6턴 2진 / 8턴 여포 출진", "조조가 서쪽에 접근하면 여포가 움직임". 진궁은 아군 부상 시 **회복을 공격보다 우선**
11. **적 레벨이 아군에 연동** — 아군 레벨을 많이 올리면 "적 장수들이 클래스업 한 상태로 나와" 난이도 급등. "장수토벌전까지는 레벨에 집착하지 말라" → 경험치 최대화가 손해가 되는 설계(우리는 공식 미확보로 스케일링 보류)
12. **전투 후 처분 선택이 전리품을 가른다** — 복양3 부호 용서(여포궁) / 추방(금 3000) → `giveGold` 근거

## 2. UI 관찰 (스크린샷 판독 — v1.2 재현 대상)

원작은 640×480 전체가 맵이고 UI가 창 밖 툴바에 있다. 우리는 패널형이라 구조는 다르되 아래를 재현했다.

| 항목 | 원작 | v1.2 반영 |
|---|---|---|
| 전투명 | 짙은 남색 바 + 흰 글자 | ✅ `.stage-name-bar` |
| 턴 | `턴 수 2/20` — 현재/최대 동시 | ✅ 임박 시 붉은 강조 |
| 승패 조건 | 상시 노출 | ✅ 조건 스트립(런타임 교체 즉시 반영) |
| 대사창 | **맵 위 말풍선** — 이름은 창 밖 좌상단 파란 글자, 초상은 화자 좌우에 따라 전환, **꼬리가 화자 타일 지목**, 최대 3줄 | ✅ SpeechBubble |
| 선택지 | 초상 좌 + `1.` 번호 + 선택 항목 풀폭 파란 바 + 흰 글자 | ✅ (전투 내는 하단 소형 크림 창) |

## 4. 우리 조사와의 차이 (교정)

| 항목 | 판정 |
|---|---|
| 전투명 | 정발판 = 청주 **황건적 토벌전** / 서주 **보복전** / 서주 **구원전** / **여포** 포위전 → v1.2에서 교정 |
| 백은개 vs **백은갑옷** | 정발판은 백은갑옷 (statuses.md 교정) |
| c03 절영 | "전멸 시"가 아니라 **이유 퇴각 시**. 서영 퇴각 → 가죽 방패 (신규) |
| c04 3책 보상 | 순욱·순유 = 칠흑도복 / 전위 = 비룡도복 (biglobe·thewiki 충돌을 블로그가 해소). 단 "전위안 = 잔존 적 Lv+1"은 블로그 미언급 → 미확정 유지 |
| c08 허저·하후돈 vs 여포 | 블로그는 **일기토**("단순히 칼을 주고 받습니다") — biglobe의 인접 대화 분류와 충돌 |
| c01 손견 | **HP 손실 상태로 개전하는 우군**, 생존 시 고정도 (신규 — 우군 보호 보물의 첫 사례) |
| 1부 보물 | 무명장갑·가죽/구리 투구·방패·칠흑/비룡 도복·백은/연환/황금 갑옷·성자보검·몰우전·복건·가죽기마갑옷·사모 = **전량 우리 데이터에 없었음** → v1.2에서 20종 신설 |

## 5. 미구현·백로그

- **오브젝트 레이어**(목책·천막·깃발·사당) — 맵 밀도 격차의 최대 원인. v1.3
- **적 레벨 스케일링**(아군 평균 연동 + 적장 클래스업) — 원작 공식 미확보로 보류. `levelUpEnemies` 이벤트가 부분 대안
- **복양 3연전 분기**(전멸 시 후속 스킵 + 보물 3종) — 우리는 1전 압축
- **⚠ 무구성장 계통 편차**: 원작 규격은 "보물 base = 상점 1단계의 1.6~1.8배, 성장 +9/Lv(상점 +10보다 낮음), 최대 Lv9 → 만렙 상점템에 **소폭 밀림**"(equipment.md §26)이다.
  우리 수치로는 의천검 16+72=88 vs 3단계 철검 55+20=75로 **보물이 앞선다**. 원인은 상점 3단계 기본치가 원작 대비 낮게 잡힌 것으로 추정.
  교정 방향은 상점 3단계 상향 또는 보물 최대 Lv 하향이며, 둘 다 전 밸런스 재검증(테스트 683 + 15전 시뮬)을 요구해 v1.3 과제로 남긴다
- 절영 +2 / 바람바퀴 +1로 넣었으나 equipment.md 표는 반대(절영 +1 / 바람바퀴 +2) — 실측 확보 시 재교정
- 확인 실패: 일기토 화면 레이아웃(블로그는 영상 전용·재생 불가), 상점·막사·전리품 결산 화면, 이동/공격 범위 하이라이트 색
