## 1. 시스템 발견 (v1.2 반영 근거)

1. **턴 제한 = 패배 조건이며 UI가 `턴 수 n/20`으로 상시 노출.** 표준 20턴, 복양3만 25턴, 원술 정벌은 선택지로 12/20 가변 → `DefeatCondition.turnLimit` 도입 근거
2. **호위 대상 사망 패배** — 헌제 구출전 "헌제의 사망" → `unitDies` 근거
3. **한 선택지가 승리조건·턴상한·전리품을 동시에 변경** — 원술 정벌(군량 지원 = 20턴·전멸·인수X / 책임관 사형 = 12턴·원술 퇴각만·인수O) → `setVictory`/`setDefeat` 근거
4. **전투 결과가 승리조건을 바꾼다** — 동탁 추격전 "퇴각한다" → 승리조건이 "조조를 서단까지"로 전환 + **적 전체가 조조를 추격** → `setBehavior` officerIds 생략(전원) 근거
5. **화염이 지형을 바꾼다** — 화공 후 불꽃 타일이 여러 턴 잔존해 통로를 봉쇄. 장수 토벌전은 이를 "불을 이용한 방어진영"으로 씀 → `hazards` 근거
6. **지형 배율이 명시적** — 기병: 풀숲 90% / 여울 80% / 가옥 90% (기존 문서는 "악지 80%"만) → terrain 교정 + `ford` 신설 근거
7. **출진 슬롯 순번 = 맵 배치 위치** — "2~3번째 자리는 선봉이라 방어 높은 장수", "빨갛게 칠한 슬롯이 성안에 갇히는 병력" → 출진 화면 인과 시각화 근거
8. **아이템은 맵에 놓여 밟아 회수**, 획득 시 `{이름}을(를) 손에 넣었습니다!` 1줄 메시지 → `groundItems`/`dropItem`/획득 모달 근거
9. **아이템 귀속**: "모든 아이템은 아군이 입수하면 조조진영으로" → 공용 창고 확증
10. **적 AI가 트리거 기반** — "3턴에 자동 공격", "4턴 1진 / 6턴 2진 / 8턴 여포 출진", "조조가 서쪽에 접근하면 여포가 움직임". 진궁은 아군 부상 시 **회복을 공격보다 우선**
11. **적 레벨이 아군에 연동** — 아군 레벨을 많이 올리면 "적 장수들이 클래스업 한 상태로 나와" 난이도 급등. "장수토벌전까지는 레벨에 집착하지 말라" → 경험치 최대화가 손해가 되는 설계(우리는 공식 미확보로 스케일링 보류)
12. **전투 후 처분 선택이 전리품을 가른다** — 복양3 부호 용서(여포궁) / 추방(금 3000) → `giveGold` 근거

## R3. c04 청주 3책 — **소스 충돌, 3책 기반 채택 + 요검증**

우리 `stage07`의 3책 효과(순욱=적 일부 퇴각 / 전위=퇴각 + **잔존 적 Lv+1** / 유인=포위 + 혼란)는 `bg` 원문과 일치한다.
「전위안 = 잔존 부대 Lv +1」은 **적군 강화**이고 아군 보너스가 아니다 (`bg` 「残った部隊は１レベル上昇する」, `tw` 「난이도가 조금 올라가는 대신 비룡도복」).

미해결은 **도복 보상의 결정 주체**다.

| 소스 | 주체 | 원문 |
|---|---|---|
| `bg:c04` | **스토리 선택지**(칙명 수락 1/2) | 「１を選択していると…漆黒の道朊 / ２を選択していると飛龍の道着」(増減幅 2 병기) |
| `tw:보물` | **전투 3책** | 비룡 = 「전위의 의견」 / 칠흑 = 「순욱이나 순유의 의견」 |
| `jojojo` | 전투 3책 | 「칠흑도복(순욱·순유), 비룡도복(전위)」 |

**3책 기반 채택.** 기각 근거 5항: ① 2 대 1 + 3책별 배치까지 서술한 상세도 우위 ② `bg`의 "1→칠흑, 2→비룡"이 3책 순서와 정확히 일치 → 같은 페이지의 인접 선택지에 규칙을 오배치한 것으로 보인다 ③ `bg` 자신이 전위안에 Lv+1 페널티를 적는데 보상이 없으면 3지선다 설계가 붕괴 ④ 해당 줄에 오타(`道朊`←`道服`) ⑤ `bg`가 그 선택지에 `増減幅：2`(사실/가상 게이지)를 병기.

**실기 판정 절차(1회)**: 청주 진입 직전 세이브 → 스토리 선택지 `1. 음, 받겠소` → 3책 `전위` → 클리어. 비룡도복이면 3책 기반 확정, 칠흑도복이면 `bg`가 옳다.

**코드 미반영 사유** — 도복 보상 자체를 아직 넣지 못했다. 원작은 **승리 후 지급**인데 우리 이벤트 DSL에 승리 트리거가 없다(현재 트리거는 battleStart·turnStart·unitDefeated·unitsMeet·reachArea). `stage14`처럼 선택 시점에 `giveItem`하면 결과는 같지만 개전 직후 획득 모달이 뜨는 연출 오차가 생긴다. **v1.3에서 `victory` 트리거를 추가해 함께 넣는다.**
