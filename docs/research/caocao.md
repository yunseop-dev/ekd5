## 1. 조조전이 영걸전/공명전 대비 바꾼 것

- **턴 순서**: 유닛별 민첩 기반 턴제가 아니다. 3작 모두 "아군 전원 → 적군 전원" 페이즈제. 민첩(순발력)은 턴 순서가 아니라 **명중/회피/2회 공격 확률**에 쓰인다.
- **반격**: 영걸전은 반격 자체가 없어 "아군 턴에 최대한 많이 죽이는" 게임이었다. 공명전에서 전 부대 반격이 도입됐고(반격 시 2회 공격도 확률 발동), 조조전은 전 부대 반격이되 **반격은 항상 1회**로 고정했다. 이 차이는 조조전 온라인에서 다시 "반격 시 2회 공격 가능"으로 회귀한다.
- **퇴각 시스템 철폐**: 영걸전·공명전은 퇴각 후 같은 전투를 다시 해 레벨 노가다가 가능했지만, 조조전은 퇴각(패배)해도 스토리가 그대로 진행된다(일부 필수 승리 전투 제외). 대신 전투 중 세이브/로드가 허용됐다.
- **적 레벨 연동(러버밴딩)**: 적 유닛의 레벨과 **상점 장비 해금 단계**(1~3단계)가 아군 평균 레벨에 연동된다. 이 때문에 고인물들은 일부러 저레벨·퇴각 플레이를 하고, 이 구조는 나무위키에서 "RPG 기본 문법(레벨업 보상)에 적대적인 근본적 단점"으로 지적된다. 상위 무기 해금은 평균 Lv20/40 근처(모드들이 이를 표준화).
- **일기토 너프**: 무조건 레벨+1 → 승리 시 일반 경험치만. 대신 전투 중 "인접 대화 이벤트"(일기토 없이 적장 사망, 설전 등)가 크게 늘어 조조전 특유의 숨은 묘미가 됐다.
- **대화 파트 축소**: 영걸전·공명전의 도시 탐사/NPC 대화가 사라지고 막사 회의(6~7인)로 축소. 자동전투(오토배틀)는 없다.

## 2. 조조전 병과 시스템

### 2.1 구성
- 총 **27종 병과**, 아군 사용 가능 **13종**. 아군 병과만 3단계 승급 가능(적 전용 병과는 승급 없음).
- 승급은 전작들의 병과별 아이템 대신 **'인수(印綬)' 아이템으로 통일**: Lv15 이상에서 인수 → 2차, Lv30 이상에서 인수 → 3차. 인수 승급 시 클래스업 보너스(HP 등)가 붙는다(승급 없이 상위 클래스로 참전한 조창은 체력이 낮다는 서술로 확인).
- 무관계(무기 장비: 검/창/활 → 공격력)와 문관계(부채/보검 → 정신력)로 대분. 문관계 = 책사·도사·풍수사·기마책사 4계열.

### 2.2 아군 13계열(승급 트리 확인분)
| 계열 | 승급 트리 | 비고 |
|---|---|---|
| 군주계 | 조조 전용 (군주→…) | 전용 책략 '패기' |
| 기병계 | 경기병→중기병→친위대 | 아군 5명(하후돈·장료 등), 3차에서 공격 범위 약점 극복 |
| 궁기병계 | 궁기병→노기병→(연노기병) | 원거리 딜러, 공격 S |
| 보병계 | (경보병)→중보병→근위병 | 방어 S급 탱커, 전 지형 100%+ |
| 궁병계 | 궁병→… | 공격 A |
| 포차계 | 발석차 계열 | 간접 광역, 유엽 |
| 적병계 | 허저 전용급 | 반격 특화 |
| 무도가계 | 전위 | 기합 사용 |
| 무희계 | 초선, 축융 | 매혹/상태회복 지원 |
| 책사계 | →→군사(3차) | 공격 책략 특화(업화·주작) |
| 도사계 | 곽가, 가후 | 환술계, 후반 활용도 하락 |
| 풍수사계 | 순욱 등 | 힐러+버퍼(회귀·수송·백호) — 문관 중 최중요 |
| 기마책사계 | 사마의 전용급 | 기동 문관, 날씨 변화(천변)·풍계 |

적/우군 전용: 황제, 제독(주유·육손), 서량기병(여포·마초계), 해적, 황건적, 곰부대, 맹호대, 주술사, 선인, 나무인형, 흙인형, 물자대, 식량대, 민중.

### 2.3 상성(가위바위보)과 구현 방식
- 공식 상성: **기병 > 보병 > 궁병 > 기병** (일본 위키 명시).
- 실제 구현:
  - 보병→기병: 추가 피해를 "받는" 게 아니라 **보병이 기병을 공격할 때 주는 피해가 절반**으로 깎이는 방식. 그래서 보병은 기병 상대 탱킹은 잘 된다.
  - 기병계(+맹호대·곰부대)는 **원거리 공격(궁병·궁기병·포차)에 +50% 추가 피해**. 구리기마갑옷(간접 피해 -50%)으로 상쇄 가능.
  - 청공검(원거리 병과 장착 가능)은 기병에 +50% — 원거리×청공검×회심이면 1.5×1.5×1.5 = **3.375배** (합연산이 아니라 곱연산).
- 영걸전의 상성은 "피격자 방어력 ±25%" 방식이었고(그래서 탱커 보병이 기병에 뚫리는 밸런스 문제 발생), 조조전에서 위처럼 재설계되어 보병 가치가 크게 올랐다.

### 2.4 지형 보정
- 지형효과는 **물리 공격/방어에만** 적용(책략·명중률 무관). 기병: 평지 110%, 대하·산지 등 악지 80% — 같은 장수가 지형만으로 30% 성능 차. 보병은 전 지형 100% 이상. 기병은 조조전에서 처음으로 숲 통과 가능(이동력 감소로 산지·가옥도 통과).

## 3. 조조전 능력치 모델

- 장수 능력치 5종: **무력, 지력, 통솔, 민첩, 운** — 모든 장수의 값이 **짝수**다. 이유: 부대 초기 능력치(Lv0) = **장수 능력치 ÷ 2**이기 때문. 열매 복용 시 장수 능력 +2 = 부대 능력 +1.
- 부대 능력치 5종: **공격력(무력), 방어력(통솔), 정신력(지력), 순발력(민첩), 사기(운)**.
- 레벨업 성장치는 병과별 등급(S/A/B/C)에 따라 결정. 공식 예시: `레벨 10, 순발 B, 민첩 90 부대의 순발력 = 45 + 3×10 = 75` (B등급 성장 +3/레벨). 만렙(50) 기준 공격 S 병과는 B 병과보다 공격력이 100 높고, A는 50 높다(등급 간 레벨당 1~2 차이).
- 특화/열화: 같은 병과의 일반 병사 대비 성장치가 높으면 특화(초록), 낮으면 열화(빨강)로 장수 개성이 표현된다.
- **경험치: 다음 레벨까지 항상 100 고정** (조조전 온라인에서 확인된 원작 사양). 막타·책략 사용·회복 지원 등으로 획득, 레벨 차가 크면 획득량 급감. 맹덕신서 착용 시 획득 경험치(장비 경험치 포함) 1.5배.
- 상태이상: **중독/금책(책략 봉인)/혼란/부동** + 매혹. 매 턴 자연 회복 확률 = **장수 운 ÷ 2 (%)** (복수 상태이상은 각각 판정). 태평청령서(매턴 상태회복), 초선(주변 상태회복) 등 해제 수단 존재.

## 4. 조조전 전투 공식 (모딩 커뮤니티 역공학 확정치)

### 4.1 데미지
```
물리 데미지 = (공격자 공격력×지형효과 − 방어자 방어력×지형효과) / 2 + 공격자 레벨 + 25
책략 데미지 = ((공격자 정신력 − 방어자 정신력) / 3 + 공격자 레벨 + 25) × 책략별 위력 계수
```
- 최소 데미지 1 보장. 계산 중간마다 소수점 버림. 여기에 소폭의 랜덤치가 가산된다.
- 지형효과는 물리에만 적용. 완전 선형 공식이라 후반엔 **공격력보다 레벨이 더 중요**해진다.
- 책략 위력 계수는 '주작 = 1.0' 기준으로 각 책략에 고정 배율.

### 4.2 물리 명중률 (순발력 비율제, 하한 30% 상한 100%)
r = 공격자 순발력 / 방어자 순발력 (정확식은 소수점 버림 포함):
- r < 1/3 → **30%**
- 1/3 ≤ r < 1/2 → `90 × r` (30~45%)
- 1/2 ≤ r < 1 → `60 × r + 30` (60~90%)
- 1 ≤ r < 2 → `10 × r + 80` (90~100%)
- r ≥ 2 → **100%**

체감 기준: 순발력 동급 = 90%, 한 등급 아래에서 위 치면 ~70%, 두 등급 차 ~45%, 세 등급 차 ~30%.

### 4.3 2회 공격(순발력 비율) / 회심의 일격(사기 비율) — 동일 공식
- r < 1 → **1%**
- 1 ≤ r < 2 → `18 × r − 16` (2~20%)
- 2 ≤ r < 3 → `80 × r − 140` (20~100%)
- r ≥ 3 → **100%**

체증형 곡선이라 버프 효과가 극적: 사기 S급(허저)이 B급 잡병 상대 회심 20%, A급(조비)은 12.8%. 연병(민첩 버프) 받은 전위의 2회 공격은 20% → 52%, 상대에 둔병(민첩 디버프)까지 걸면 100%. 회심 데미지는 1.5배(간접공격 추가피해와 곱연산).

### 4.4 책략 명중률
물리 명중 공식에서 순발력 대신 **(정신력 + 사기)** 를 대입해 기본 확률을 구한 뒤, **책략별 한계 명중률(가중치)** 를 곱한다:
- 100% (무조건 성공류), 1.0배(초열급), 0.9배(업화급), 0.8배(화룡급), 0.6배(폭염급), 0.5배(현혹급), 0.33배(해일급).
- 예외 알고리즘 존재(무희의 유혹 보정 등).
- 실전 함의: 무관에겐 정신 버프보다 **사기 버프가 책략 방어에 효과적**, 적 문관에겐 정신 디버프가 효과적.

### 4.5 반격
- 직접 공격에만 발동, 항상 1회(2회 공격 없음). 간접(원거리)·책략엔 반격 불가. 청룡언월도 등 "반격당하지 않음" 무기 존재.

## 5. 조조전 책략 시스템 (MP·사거리·위력 계수 샘플)

- 속성: **화계 / 수계 / 풍계 / 토계(지계) + 사신계(주작·청룡·백호·현무) + 보조/회복/방해계**. 지형·날씨 제약이 핵심 설계: 화계는 평지/숲/가옥/성/다리 가능·우천 불가(성 내부에 유효한 유일 속성), 풍계는 건물/숲 외 전부 가능·날씨 무관, 사신계는 지형 무관(주작은 맑음 필요, 보석 아이템 필요).
- 전작과 반대로 조조전은 **약한 책략일수록 사거리가 길다**(영걸전·공명전은 강한 책략일수록 범위·사거리가 넓었음). 그런데 조조전의 짧은 사거리가 영걸전의 긴 사거리보다 길어서 문관 활용도가 급상승.
- 확인된 수치 샘플 (책략치 소모 / 사거리 / 위력[주작=100%] / 한계명중):
  - 초열 6 / 4 / 70% / 100%
  - 업화 10 / 3 / 90% / 90%
  - 화진 12 / 4 / 십자 범위 / 50% / 90%
  - 화룡 20 / 3 / (범위기)
  - 선풍 6 / 4 / 50% / 100%
  - 회오리바람 10 / 4 / 70% / 90%
  - 풍진 12 / 4 / 사각 9칸 / 40% / 100%
  - **모래폭풍 24 / 사거리 무한(맵 전체) / 20% / 90%** — 후반 야전 최강기
  - **주작 40 / 4 / 100% / 100%** — 단일 위력 업화 초과의 광역기
  - 기합 3 / 자신 (공격력 or 정신력 증가), 패기 8 / 자신 (공/방/민/사기 동시 증가, 군주 전용)
- 풍수사의 **회귀(아군 재행동)**, **수송(무제한 사거리 대보급)**, **백호(전체 회복+상태회복)**, 강행(이동+2)은 밸런스 붕괴급 — "모래폭풍-회귀 무한 콤보"가 대표 치트성 전술.
- 오화신염선(화계 +20%), 파초선(풍계 강화 — **한국 정발판은 버그로 지계가 강화됨**) 등 속성 강화 보물과 연동.

## 6. 아이템·보물 시스템 (조조전의 대표 신규 시스템)

- 슬롯 3개: **무기 / 방어구(갑옷·옷) / 보조구**. 무관계는 갑옷, 회피형·문관계는 옷. 보조구는 방패·장갑·기마갑옷·서적·보석·관 등.
- **무구성장(장비 레벨업)**: 무기는 공격할 때, 방어구는 맞을 때 장비 경험치 획득. 일반(상점) 장비 최대 **Lv3**, 보물은 최대 **Lv9**. 보물의 레벨당 상승치(4~12)는 상점 장비보다 낮지만 Lv1 초기치가 높고 고유 특수효과가 진짜 가치. → "문관 4명이 둘러싸고 평타로 맞아주는" 방어구 노가다 같은 그라인딩 메타가 생겼고, 이것이 유명한 장비 레벨링 노가다 문제(신규 유저에게 불친절)의 근원.
- **보물 50종 + 보물도감**: 전투당 약 1개 등장(적장 격파 드랍·창고·이벤트). 도감은 세이브가 아닌 **게임 데이터 전역에 귀속**, 50종을 다 모으면 회차 시작 시 허자장이 전 보물 지급(거절하면 금 10,000). 사실 전용/가상 전용 보물이 있어 도감 완성엔 최소 2회차 필요.
- 대표 보물 효과 유형: 스탯·명중 보정(방천화극·장팔사모=찔러 공격), 상성 차단(거울갑옷=간접공격 무효), 피해 경감(구리기마갑옷 -50%), 경험치 증폭(맹덕신서 1.5배), 타 병과 책략 사용(둔갑천서), 매턴 상태회복(태평청령서), 속성 강화 부채류.
- 전투 중 창고/상점 이용 가능("XX, 창고를 열어라!"), 상점 장비는 아군 평균 레벨에 따라 1~3단계 해금(가상 모드는 첫 전투부터 3단계 구매 가능).
- 영걸전(PC)은 장비 슬롯 자체가 없었고(보물=패시브 스탯 부스터), 공명전에서 상점 무기 구매가 도입, 조조전에서 위 시스템으로 완성 — 나무위키는 보물 시스템을 "조조전 재미의 최대 지분"으로 평가.

## 7. 사기·의욕 계열 시스템의 변천

- **영걸전**: 유닛 = 병력(HP, 천 단위) + **사기치**. 사기가 공격력·방어력에 직접 반영되고, 피격량 비율·사기 저하 책략으로 하락, 낮으면 혼란 돌입. 날씨가 매 턴 변화(비=화계 봉인).
- **공명전**: **사기 폐지** — 대신 능력치 버프 보조 책략 체계로 대체. 숨은 고정 스탯 **'공격속도'** 가 2회 공격 확률을 결정(조조전 민첩의 전신, 부대별 고정치). 혼란이 3~4턴 지속되는 강력한 방해 요소로 부상.
- **조조전**: 사기가 **다섯 번째 부대 능력치**(장수 '운' 기반)로 부활하되 역할이 재정의됨 — 공/방이 아니라 **회심의 일격 확률, 책략 명중/저항**에 관여. 사기 버프/디버프 책략(격려·욕설 등)이 확률 게임의 핵심 레버.
- '의욕(やる気)'이라는 명칭의 별도 게이지는 삼국지 3부작에는 없고(노부나가전 계열 요소), 위 사기 시스템이 그 역할이다. ※확신도 중간.

## 8. 일기토·설전

- **영걸전**: 시스템적 보상이 가장 큼 — 일기토 발생 시 해당 장수 **무조건 레벨 +1**(경험치 100 상당, 잔여 경험치 유지). 다수의 적 네임드가 일기토로 즉시 퇴각/사망 처리되므로 공략 수단이자 보스 처리기. 아이템 획득 일기토(삼첨도, 적로 등)는 레벨 안 오름. 발동은 특정 전투에서 특정 아군↔적장 인접/공격. PC판은 전용 애니메이션(관우·장비·여포만 고유 모델).
- **공명전**: 일기토 다수 유지 + 버그 포함(오반·요화가 일기토로 '사망'해도 계속 사용 가능 등).
- **조조전**: 일기토 승리 시에만 일반 격파 경험치. 공짜 레벨업 삭제. 대신 **인접 대화 이벤트/설전**이 대폭 확대(일기토 없이 인접만으로 적장 사망·아군 합류·보물 획득 등) — 초반엔 화려하다가 후반으로 갈수록 부실해진다는 평.

## 9. 스토리 분기 — 조조전의 사실/가상 게이지 (수치 확정)

- 스토리 중 선택지마다 **파랑(사실)/빨강(가상) 게이지**가 변동한다(예: 마등을 처형할지 살려줄지). 친밀도/신뢰도 수치 시스템은 없고, 오직 이 게이지 하나로 분기.
- **1차 분기: 30번째 전투 '마초 요격전' 종료 시점 — 가상 게이지 85 이상이면 가상 모드, 85 미만이면 사실 모드.**
- **엔딩 3종**:
  1. **가상 엔딩** (마초 요격전 후 가상 85↑): 순욱 생존 라인 → 관우 사망 후 **마왕에 씐 제갈량 타도**라는 파격 전개, 최종전 오장원 결전. 엔딩 연도 221년.
  2. **사실 엔딩**: 사실 모드 진행 중 비전투 선택지 2회로 게이지 추가 조정 가능 — 마지막 전투 '건업 침공전' 후 **사실 게이지 85 이상**이면 사실 엔딩(225년).
  3. **중간 엔딩**: 건업 침공전 후 사실 게이지 85 미만 — **조비가 황제로 등극**하는 엔딩.
- 장수 생사 분기: **곽가** — 유성 평정전 이후 생존/사망 분기. 생존 시 적벽대전 난이도가 크게 하락(전략 조언), 사망 시 최상급 보물 **둔갑천서** 획득 → "곽가를 살릴 것인가 둔갑천서를 얻을 것인가"가 시리즈 대표 딜레마. 사망 장수는 이후 전투에는 참전해도 시나리오에서는 사라진다(존재 증발 문제로 비판).
- 여포궁/이광궁(복양 전투 클리어 방식), 하후연·방덕 생존 여부 등도 보물 획득 분기와 얽힘.
- 참고 — 전작들의 분기: 영걸전은 루트 선택(거록/청하 등)과 **맥성에서 관우 구출 여부**가 3·4장 전개와 엔딩을 좌우. 공명전은 **제갈량 수명 게이지(하트 5개)** — 총퇴각 5회당 하트 절반 감소(상급 난이도는 장 종료마다 반 개 감소), 오장원 전 소진 시 배드 엔딩(추풍오장원) 확정. 콘솔판 공명전은 프롤로그 선택지 + 파서 전투 14턴 클리어로 방통 생존 → 관우 구원 → 유비 자연사 루트까지 존재.

## 10. 공명전 고유 시스템 정리

- **난이도 선택 도입**(초급/상급) — 시리즈 최초. 상급은 적 책략 난사(위정보/위병 혼란 지옥) + 제갈량 수명 감소 가속.
- **제갈량 수명 게이지**(하트 5개)와 **총퇴각** 페널티 → 멀티 엔딩.
- **숨은 스탯 '공격속도'**: 부대(클래스)별 고정, 2회 공격 확률 결정. 레벨업으로 안 오름.
- **성장 난수/고정 분리**: 아군은 레벨업 성장치 랜덤, **적군은 고정 성장**(무·지·통은 아군 평균치, 내구력은 최대치-1) → 적에서 아군으로 합류한 장수(하후패·왕평·이엄 등)가 내구력 이득 + 합류 장수는 1레벨분 성장치 추가 보정.
- 병과 구조: 3단 클래스(군사/보병/궁병/기병/궁기병/전차/포차), 2단(무도가/맹수/산적), 1단(식량대/물자대/군악대/남만기병), 적 전용(총사령관/황제). 대무도가(장억)는 "일반 클래스 최강"으로 악명. Lv15/30 도달 시 승급.
- 밸런스 실패 사례: 적 레벨이 아군보다 항상 낮게 설계(조운·장억 둘이서 클리어 가능 = "조운장억전"), 적은 상점 장비도 없이 맨몸 → 조조전의 "적 레벨 연동" 설계는 이에 대한 정반대 처방.
- 진형(陣形)·병량(兵糧) 시스템은 없음(그건 본가 삼국지·손자병법 계열).

## 11. 스테이지 디자인 패턴 (3부작 공통 문법)

- **승리 조건 다양화**: 적 전멸 / 미션 보스 격파·퇴각 / 특정 지점 도달(신도성 성문) / 거점(성채) 점령 / 시간 벌기·호위(장판파 민중 탈출) / 구출(맥성 관우 구원). 복수 승리 조건 + **달성 방식별 보너스 경험치**(전원 +50 등)가 표준 — "군량고 점령하면 전원 +50이라 일기토를 포기한다" 같은 트레이드오프 설계.
- **증원(원군) 웨이브**: 장판파 2연전(2차전에서 적 부활), 조조전 후반 개떼 물량전(오장원·정군산·적벽). 우군(초록) NPC 부대 동행 — 영걸전에선 NPC가 경험치를 스틸해 원군 요청이 함정으로 악명.
- **턴 제한 보상**: 가상 모드 정군산 전투 — **10턴 내 클리어 시 옥새**. 공명전 콘솔판 파서 전투 14턴 내 클리어 → 방통 생존.
- **기믹**: 날씨(비/눈 = 화계 봉인, 사마의 '천변'으로 조작), 적벽의 동남풍·화계 이벤트, 성채/마을의 매턴 자동 회복(이를 역이용한 장비 노가다), 1칸 길목+성채 우주방어(허저), 관문 방어전(가상 양평관 — 조홍·방덕이 관문 수문장 고정), 발석차의 지형 무시 포격, 전투 중 창고/상점.
- **강제출진/출진불가**: 조조전은 장수마다 스토리상 강제출진·출진불가 전투가 정의되어 있음(예: 곽가 — 여양·업성·유성 강제, 장판파 불가). 리메이크 시 데이터 테이블로 관리해야 하는 축.
- **루트 선택**: 영걸전 거록/청하처럼 루트별 난이도·동료·아이템이 달라지는 갈림길(쉬워 보이는 루트가 다음 전투를 어렵게 하는 함정 설계 포함).

## 12. 조조전 MOD 씬 — 팬들이 "코어"라고 검증한 요소들

- 역사: 중국에서 시작(여포전, 조운신전, 원소전, 환세무쌍) → 한국의 '조사모' 매니저 레가시가 번역 → 전용 에디터(전투/스토리/텍스트/그래픽)가 만들어지며 한국 제작 폭발. 중국 유저들이 원작을 초월 개조한 **신조조전**은 사실상 팬 게임 엔진이 됐고, 코에이는 20년간 묵인 + **조조전 온라인 제작 시 모드 제작자를 채용**.
- 대표작: 성 삼국지촉한전(유비, 역대 최고 평가·정사 기반), 관우전(한글 원본 모드), 무왕제의전, 대전투패치(최대 30인 전원 출진) 등.
- **모드들이 표준화한 시스템 변경**(= 팬이 생각하는 개선 방향의 증거):
  - 승급 레벨을 원작 15/30 → **20/40**으로 조정(장비 해금 20/40과 동기화), 일부는 3차·4차 전직(Lv60 인수) 추가.
  - **난이도 모드**: 일반/도전/지옥/신화 단계, 최저 난이도는 아군 +10% 버프·최고 난이도는 적 +20% & **난수고정**(세이브로드 신공 봉쇄).
  - **공훈 모드 / 열매 모드**: 전투 성과 포인트로 성장 재분배·도핑을 시스템화.

## 13. 삼국지조조전 Online (넥슨×코에이, 2016.03 ~ 2020.06.11 종료)

원작 유저와 모더를 흡수하기 위해 만든 공식 리메이크. **원작보다 유저 모드의 영향을 크게 받았다**(나무위키 명시). 원작 대비 변경점이 리메이크 설계에 특히 유용:

- **협공**(신규): 인접한 미행동 아군이 있으면 행동 소모 없이 추가 타격(근접 한정). 원거리는 **지원 공격** 효과로 대응. ZOC·배치 전략성이 급상승했다는 호평.
- **반격 강화**: 원작과 달리 반격 시에도 확률 2회 공격 발동. 무반격 특성·사거리 밖 공격만 반격 회피 가능.
- **경험치 재설계**: 물리 공격은 타격한 적 수만큼 인분 획득(광역 3명 = 3인분), 책략 막타에 추가 경험치. 획득량 = 레벨 차 기반(물리 1~17, 공격 책략 1~150, 버프/회복 1~25). 필요 경험치: ~Lv20 110–120, Lv20–40 `레벨×10−80`, Lv40–60 `레벨×10−100` (**원작은 전 구간 100 고정**).
- **피해 공식 평탄화**: 레벨 차 20에도 0데미지/원킬이 안 나오게 조정 → HP 가치 상승.
- **팔괘석**: 서 있으면 MP % 회복 + 지형 110% 보정을 주는 신규 타일.
- 콘텐츠 구조: 스토리 **연의**(조조전 리메이크 + 유비전·여포전·관우전·조운전·서서전 등 외전 연의), 전략(영토 점령+비동기 PvP 공성전, 출진 **COST 제한** 최대 99), 섬멸전, 천리행, 사신전, **경쟁전**(PvP), 몽매의 시련.
- 실패 요인(반면교사): 장수 공격력 인플레 + "금격 방어술·최대 피해 방어" 같은 **저확률-고파워 시스템**으로 확률 의존 심화, 유저가 반대한 **보물 강화**와 **특화 전장** 강행 → 병종 밸런스 붕괴 → 서비스 종료.

## 15. 리메이크 관점 시사점 (증거 기반)

1. **조조전 공식은 전부 선형·정수 연산**(소수점 버림)이라 웹 구현·검증이 쉽다. 모딩 커뮤니티 공식을 단위 테스트로 그대로 옮길 수 있다.
2. 팬덤이 20년간 유지·표준화한 것: 보물 성장/도감, 사실·가상 게이지 분기, 회귀·주작·모래폭풍 같은 한 방 책략, 인접 대화 이벤트. 팬덤이 일관되게 고친 것: **장비 레벨 노가다, 확률 의존(난수고정 옵션), 승급 15/30↔장비 20/40 불일치, 난이도 단일**. 리메이크는 전자를 보존하고 후자를 옵션화하는 것이 안전하다.
3. 조조전 온라인의 협공/지원공격은 호평, 보물 강화·특화 전장은 서비스 종료급 반발 — "성장은 수평(전략적 선택), 수직 강화는 금물"이 팬덤의 합의에 가깝다.
